For the last year or so, every project I've shipped has had its writeup buried in a GitHub README. That works fine for code — README-as-documentation is the default for a reason — but it's a bad fit for the kind of writing I actually want to do: walkthroughs, lab notes, and the occasional reflection on how the certification grind is going.

So here we are. This site is the new home for that writing. The repos still live on GitHub; the *prose* about the repos lives here.

A few things you can expect:

- **Walkthroughs.** Long-form notes on labs, modules, and tooling — the kind of thing I would have wanted to read when I started.
- **Project writeups.** Each project on the [Projects page](/projects/) has its own entry with context, stack, and links to the underlying code.
- **A `/now` page.** What I'm focused on right this minute — updated whenever something material changes.
- **Honest notes on the certification path.** What's working, what isn't, and what I'd skip if I started over.

If you're reading this from the GitHub profile README — welcome. The README itself will keep pointing here for the longer-form material.

Onward.
